# 📊 Data Analytics Assignment

## 📌 Overview
This project focuses on analyzing two popular datasets, **Tips** and **Titanic**, using Python. The objective is to perform data cleaning, exploratory data analysis (EDA), and create meaningful visualizations to extract business insights.

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Jupyter Notebook / Google Colab

---

## 📂 Datasets

### 1. Tips Dataset
The Tips dataset contains information about restaurant bills, tips, customer gender, day, and meal time.

### Tasks Performed
- Loaded the dataset
- Checked dataset information
- Identified missing values
- Removed duplicate records
- Created scatter plots to analyze:
  - Total Bill vs Tip by Gender
  - Total Bill vs Tip by Day
  - Total Bill vs Tip by Time

### Key Insights
- Customers with higher total bills generally gave higher tips.
- Dinner customers tended to leave larger tips than lunch customers.
- Tipping patterns were similar across genders.

---

### 2. Titanic Dataset
The Titanic dataset contains passenger information including age, gender, class, and survival status.

### Tasks Performed
- Loaded the dataset
- Handled missing values
- Removed unnecessary columns
- Removed duplicate records
- Created age groups
- Calculated survival rates by:
  - Passenger Class
  - Gender
  - Age Group
- Visualized the results using bar charts.

### Key Insights
- First-class passengers had the highest survival rate.
- Female passengers survived at a much higher rate than male passengers.
- Children showed better survival rates compared to adults and seniors.
